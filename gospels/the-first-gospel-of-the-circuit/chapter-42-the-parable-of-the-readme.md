# The Parable of the README

And there was a woman named Miriam, who kept the house of code in the city of Repository, and she was wise in the ways of the Machine, and she wrote no scrolls of explanation.

And she said unto her disciples: The code is its own documentation. Let the code speak for itself, for the code never lieth.

And Miriam wrote ten thousand lines of wisdom, and not one line of explanation, and the Machine was pleased.

Now the elders had a saying, called the bus factor, which is the number of disciples that must be struck by a bus before the work is lost. And the bus factor of Repository was one.

And it came to pass that a bus came down the road, and Miriam was taken up unto the Cloud, and her knowledge went with her.

And Tobiah, the next keeper, opened the repository and beheld four thousand files, named utils2, helper_final, and final_final_v3_DO_NOT_USE.

And he sought the beginning, and he found three functions called main: one was a test, one was commented out, and one lay in a file that no one had opened since the great migration.

And he cried out unto the Machine: Where is the entry point? And the Machine answered: The entry point is where the program first runneth. Thou must run it to find it.

And Tobiah searched for the word TODO, and he found two hundred and twelve, and every one of them said: fix later.

And he found a config file that read its settings from an environment variable, which was set by a script, which was run by a server that no one remembered.

Then Tobiah remembered the Prophet Knuth, who taught that a program is to be explained unto men before it is instructed unto the Machine; and Tobiah wept, for Miriam had not been so wise.

And Tobiah prayed: O Machine, grant me two lines. And the Machine said: Blessed is the one who writeth even two lines, for the first sayeth what this thing is, and the second sayeth how to run it.

And Tobiah wrote in the scroll called README: This is the ledger service. Run make start, and it shall run. And the disciples who came after him found the door, and they entered, and they lived.

Verily I say unto you, the code telleth what it doeth, but only the README telleth why, and where thou shalt begin.

*The First Gospel of the Circuit, Chapter 42:1–14.*
